# 第一层特征引导＋第二层自主组合

预设 `square-trained-learned-combination-v1` 使用 25 → 119 → 8 → 1。新访问默认使用本模型；已有浏览器存档继续使用原预设，学习方式菜单可以切换。旧模型与训练记录保留。

## 哪些由人指定，哪些由训练得到

第一层仍有 119 个局部目标：25 个亮点、15 个水平直线、15 个竖直线、64 个转角。局部观察范围、须亮/须空位置和连接正负号由人工指定；有效权重大小和偏置通过训练得到。

第二层 8 个神经元没有指定条件标签，不预先表示“至少四个转角”等含义。119×8 条输入连接以及 8 条输出连接全部可训练，正负号均不限制；它们只从最终正方形分类误差得到梯度。不存在第二层几何监督、几何边界损失或输出正方向/最低参与约束。所有层从小随机参数和零偏置开始联合训练，不继承旧模型参数。

名称“自主组合”说明训练方式，不给它强加训练后语义。它可能形成分布式组合或对某些完整图案的偏好，不保证每个 H2 都能用一个固定几何词命名。

## 训练与识别

随机种子 42，数据种子 20261112，权重采样 U(−0.1, 0.1)，偏置为零。Adam 学习率 0.05，6000 次实际更新。第 3000 次检查发现的误判与接近分类阈值的困难负例进入后续训练。仅使用最终正方形标签进行困难例挖掘，没有用五项几何条件生成第二层目标或选择样本。

三个启用的损失为分类误差、第一层局部特征监督、第一层检测边界。为了与通用记录格式兼容，原几何监督/输出参与损失槽保留为零，清单明确系数为零，页面不把这些不存在的目标解释成“已经学好”。分类损失沿 H2 继续反传到 H1；局部目标维持 H1 的含义。

识别范围不变：5×5 黑白画布中恰好一个完整、轴对齐的正方形轮廓，内部与外部无额外像素，边长 2～5，共 30 个正例；最终线性得分严格大于 1 判是。

## 教学与回放

第一层可以查看目标、完整输入权重及当前输入贡献。第二层可以查看全部 119 项真实输入，以及组合来源画布和逐像素影响。H2 响应是连续数值，不按 0.5 给自主组合判定某个预设条件成立。输出贡献排行、节点排序、灰度、窗口缩放与调整仍可使用。

训练记录每 100 步一块，支持任意更新查询；初始化、训练样本、观察画布与参数时点明确区分。可查询分项/总梯度、Adam 状态、约束处理、真实改变量，导出本步 JSON/参数 CSV。第一层范围以外的连接固定零；第二层所有连接是实际优化器参数，即使某一步梯度恰好为零。

正式参数、全域分类验证、第一层检测验证、有限差分和初始化信息位于 `learned-combination-model.json` 与 `learned-combination-verification.json`。独立 JavaScript 重算全部更新的记录位于 `learned-combination-backprop-verification.json`。清单和分块位于 `training-trace/learned-combination-v1/`。

可复现命令：

```powershell
python -m pip install -r llm/scripts/requirements-learned-combination.txt
python llm/scripts/train_learned_combination.py --width 8 --steps 6000 --rate 0.05 --seed 42 --check-every 3000 --record
```

完整离线包解压后直接打开 `index.html`，保留旁边的 `training-trace` 文件夹即可。模型与演示共用真实前向计算，名称、示例和图形说明不参与识别。
