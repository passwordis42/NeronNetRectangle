# 单隐藏层部分特征解释教学

直接打开 `神经网络教学.html`，选择 **真实训练教学 → 部分解释 · 6 个方框 · 25 明确 + 25 自由学习**。HTML 已嵌入模型和脚本，离线打开即可使用。

## 当前入口：六个方框，一半特征自由学习

网络结构为 `25 → 50 (tanh) → 1 (linear)`，只有一个隐藏层，全部 **1,351 个参数**参与训练。

- **25 个明确特征**：24 条边和 1 个转角，人工指定局部检测目标，施加特征监督。
- **25 个自由学习特征**：不指定形状含义，展示实际输入权重和输出贡献。
- **6 个组合示例**：居中 3×3、左上 3×3、右下 3×3、左上 4×4、右下 4×4、外圈 5×5。

明确特征与自由学习特征采用固定混排顺序，刷新不会重新随机排列。训练后的神经元整体重排：输入权重、隐藏偏置、输出权重、检测目标和示例索引同步移动。它们仍是原来经过训练的特征，编号不表示学习顺序。居中 3×3 的上／下／左／右四边对应 H1-21、H1-33、H1-22、H1-7。

点击方框缩略图会同步更新画布、四条边和对应神经元详情。再用“完整方框”“缺一格”“内部多一点”观察响应和得分变化，也可以直接编辑像素。四条边齐全仍需其他神经元判断整体是否合法。

计算展示为“四条边贡献 + 其余 46 项贡献 + 偏置”，可展开全部 50 项；其余 46 个神经元包含 21 个明确特征和 25 个自由学习特征。所有响应、贡献和最终得分均来自页面统一的 `forward()`，示例位置和特征名称不参与识别。

本模型训练时从旧版组合模型初始化 13 个局部特征，为新增 12 条边设置局部初始化，再训练全部参数。仅边与转角施加局部目标监督，不引入全解释版的完整轮廓／缺角模板，也不固定背景连接为零。外围像素可以轻微影响连续响应，但已验证不会改变明确特征是否被检测到的结论。

识别范围保持不变：5×5 黑白画布上恰好一个完整、轴对齐、边长 2～5 的正方形轮廓，内部和外部无多余像素，共 30 个正例。线性得分严格大于 1 判为正方形。

## 验证结果

### 反向传播回放

当前 v4 模型增加“前向计算 / 反向传播回放”切换。步骤 0 是真实初始化，10 个讲解阶段分别停在第 1,200、2,400……12,000 次更新后。可以直接输入任意更新编号，也可用“上一次更新 / 下一次更新”逐次查看。

初始化继承旧组合模型并为新增局部特征初始化；记录通过固定种子重新训练生成，不能称为当时留存的日志或从全随机网络训练十次。所有历史记录映射到当前混排编号，默认查看 H1-21 对应的居中上边。保留全部偏置。

每步包含实际有序训练批次、分类间隔误差、局部特征监督、检测边界与四边贡献约束，以及所有 1,351 个参数的梯度、更新前后数值和 Adam 一阶/二阶矩、偏差修正与裁剪。单样本贡献使用整个批次的归一化系数，不能当成整批次梯度。分类误差已满足间隔时为零，Adam 仍可能因已有动量更新。

页面的“当前观察画布”可自由修改；历史训练样本不变。画布使用所选步骤更新前、更新后或最终发布精度的参数，均复用同一个前向函数。最终发布时保留六位小数不是另一次训练。默认显示六位小数，非零小量用科学计数法；可切换完整精度，并导出当前步 JSON 和全部参数 CSV。

新增源码为 `backprop-core.js`、`backprop-teaching.js`、`backprop-teaching.css`，由原打包脚本内嵌。`scripts/record_training_trace.py` 复用原训练函数，且不覆盖模型或检查点。`training-trace/v1/manifest.json` 绑定当前模型哈希与编号映射；120 个数据块每块记录 100 次更新、块起点和终点的参数/优化器状态、逐次总梯度及样本编号和正例数量。

数据为 gzip 压缩的 Float64 / Uint32 小端二进制，经脚本数据封装以兼容 `file://`。载入时核对 SHA-256，在 Worker 中还原 Adam 状态并重新计算当前步的四类损失和梯度分项。页面只缓存最近四块，按需加载，缺失或损坏的记录显示错误并支持重试。

全部 12,000 次更新已在 Python 中重算梯度和状态；梯度最大误差约 `8.88e-16`。JavaScript 独立核验全部 Adam 更新，当前环境与记录的最大误差为零，验收容差 `1e-10`；交互时梯度/损失重算容差 `1e-8`。两层权重和偏置通过四类损失的有限差分检查，另覆盖动量、零梯度与裁剪。最终六位小数参数逐项一致，复现最终模型再次穷举零误判。

`scripts/build_site.py` 生成在线站点与 `downloads/neural-network-offline.zip`（约 132 MB）。离线包解压后直接打开 `index.html`，保留旁边的记录文件夹。浏览器验收覆盖断网使用、缺失/损坏数据重试、所有阶段、100/101 与 6,000/6,001 边界、导出、刷新恢复、桌面和窄屏，以及原有模型存档。

复现与验证：

```powershell
python llm/scripts/record_training_trace.py
python llm/scripts/bundle_composition.py
node llm/tests/backprop.test.cjs
python llm/scripts/build_site.py
```

### 原有模型验收

正式六位小数模型在第 2 轮、**12,000 步**训练后通过：

- 穷举 **33,554,432** 种输入，**零误判**。30 个正例最低得分 **1.601737**，其余图案最高得分 **0.867879**。
- 25 个明确检测器通过满足／不满足目标的严格正负响应验证，线性极值覆盖全部外围像素变化。
- 六组四边的像素并集分别恰好等于各自轮廓。各条边贡献至少 0.1（实际最小约 **0.142579**）；四项响应置零后的得分下降至少 0.4（实际最小约 **0.668910**）。置零干预仅用于离线验证。
- 页面原始 JavaScript 前向函数另检查 **19,637** 个正例、扰动和随机输入，以及全部特征极值、六个组合、50 项求和与预设核验。
- 浏览器检查覆盖六个缩略图直接切换、缺边／内部多点、画布编辑、明确与自由神经元详情、完整网络、导入导出、刷新恢复、新旧存档隔离、桌面 1600×1050 与窄屏 390×844；旧模式回归通过。
- 混排后的六位小数模型重新通过全部 **33,554,432** 种输入的零误判验收；逐项核验参数映射，JavaScript 对 19,637 个输入比较重排前后得分，差异小于 `1e-12`（仅浮点累加顺序导致的末位误差）。25 个检测目标及六组四边贡献也重新验收。

原自由学习、特征引导的单层／双层、人工教学和普通实验模式继续保留。首次更新会将原组合／全解释入口切到新版部分解释，但旧存档不被覆盖；之后手动选择的模式照常恢复。新版各个示例（包括第六个）、画布及详情状态独立保存。导入时参数须与相应正式模型完全一致才保留教学特征名称，修改过参数的文件按普通实验模型加载。

原顺序 v3 的画布和查看状态会在首次使用 v4 时复制，选中的隐藏神经元按新编号映射到同一个特征；旧存档不修改。旧版导出文件仍按 v3 原权重和编号加载，可通过对照选项返回。v4 导出额外包含双向编号映射和重排验证记录。

全解释对照模型仍为 13 个边与转角、30 个待补角轮廓、30 个缺角检查，使用输入权重正负及固定零连接约束。其 1,972 个参数中 1,669 个参与训练，303 个连接固定为零，18,000 步后通过全输入零误判。缺角检查检测成功时，正响应乘负输出权重减分；不匹配时，负响应乘负权重可能加分，最终仍需合计全部项。

## 文件与复现

- `partial-features-shuffled-model.json`：当前混排模型、25 个特征、六个示例、双向编号映射及训练和验证记录。
- `partial-features-model.json`：保留原顺序的训练模型（v3），也是混排模型的来源。
- `composition-model.json`、`all-features-model.json`：独立保留的旧组合和全解释模型。
- `composition-teaching.js`：四个模型共用的教学视图源码。
- `scripts/train_partial_features.py`：当前模型的定义、初始化和验收入口。
- `scripts/shuffle_partial_features.py`：用固定种子 20261016 重排已训练模型，并重新进行全输入验收。
- `scripts/train_composition.py`：旧版训练入口及共享训练／验证函数。
- `scripts/train_all_features.py`：全解释模型的结构约束训练与验证。
- `scripts/bundle_composition.py`：将四个已通过验收的模型及视图源码嵌入 HTML，并核对混排来源。
- `tests/partial-features.test.cjs`、`tests/composition.test.cjs`、`tests/all-features.test.cjs`：新旧模型的页面实际前向计算与预设回归。

从项目根目录运行。训练使用 Python、NumPy 2.4.3、种子 42、单线程 BLAS：

```powershell
python -m pip install -r llm/scripts/requirements.txt
python llm/scripts/train_partial_features.py
python llm/scripts/shuffle_partial_features.py
python llm/scripts/bundle_composition.py
node llm/tests/partial-features.test.cjs
node llm/tests/composition.test.cjs
node llm/tests/all-features.test.cjs
```

当前训练每轮 6,000 步，默认最多 16 轮；每轮穷举六位小数模型并挖掘困难负例。仅当分类、25 个检测器及六组四边贡献全部合格时写入正式模型。检查点为 `llm/.partial-features-checkpoint.npz`，可以用 `--resume --rounds 24` 延续训练。旧模型的检查点保持独立。相同数值环境可复现；其他 NumPy/BLAS 环境仍须通过全部验收。

重新生成并验收当前混排模型（不重新训练）：

```powershell
python llm/scripts/shuffle_partial_features.py
```

原顺序部分解释、旧组合和全解释模型可分别用各自训练脚本加 `--verify-only` 验收。修改视图后重新打包并运行三个 JavaScript 检查；不要手动修改 HTML 中 `BEGIN COMPOSITION BUNDLE` 标记之间的生成内容。
