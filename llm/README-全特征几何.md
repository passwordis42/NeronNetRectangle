# 全特征几何教学：单层与双层

新增两个独立预设，旧模型和旧训练记录仍可选择。新访问默认使用双隐藏层；已有浏览器存档不被覆盖。

| 预设 | 网络结构 | 含义 |
|---|---|---|
| `square-trained-geometry-single-v1` | 25 → 352 → 1 | 119 项局部支持特征与 233 项局部违规证据共同输出 |
| `square-trained-geometry-double-v1` | 25 → 119 → 5 → 1 | 局部点、直线、转角先形成响应，再输入五项几何条件 |

识别范围为 5×5 黑白画布中恰好一个完整、轴对齐的方框轮廓。边长为 2～5，内部与外部没有额外像素，共 30 个正例；线性得分严格大于 1 判是。

## 输出贡献排行

实时网络结构窗口内的“贡献排行”按 `|上一层响应 × 输出连接权重|` 从大到小排列，保留正负号、零项和全部条目。贡献栏位于网络右边，窗口较窄时放到网络下方；使用窗口顶部的“显示贡献／隐藏贡献”按钮切换。单层模型查看 352 个 H1 项；双层模型查看直接连接输出的 5 个 H2 项。偏置单列，完整求和仍与实际前向得分一致。

点击神经元名称查看特征，点击“查看输出连接”定位该连接的权重和计算。排行默认六位小数，可开启完整精度；排序始终使用完整数值。回放中跟随网络选择的历史步骤、训练样本或观察画布及参数时点，加载期间不显示旧排行。偏导来源切换不会改变这些前向贡献。

普通实验支持选择不同输出；没有隐藏层时列出输入贡献。非线性输出先显示贡献加偏置得到的 `z`，再显示激活结果。该排行描述当前输入的直接加分与减分，不表示梯度或跨层影响。

## 调整窗口布局

拖动区域之间的分隔边界可以调整画布、输出判断、网络、贡献和详情的大小；回放的左右分区及网络／详情的上下分区也支持调整。尺寸单独保存在浏览器中，缩小窗口时按可用空间限制，恢复大窗口后可继续使用原尺寸。隐藏贡献会把空间还给网络。

双击边界恢复该区域的默认尺寸，窗口顶部“恢复默认布局”重置全部尺寸并显示贡献。边界可用 Tab 聚焦，方向键增减 10 像素，Shift 配合方向键增减 50 像素，Home／End 到达最小／最大尺寸。手机支持上下调整以及详情抽屉宽度调整。所有布局操作只改变显示，不修改画布、模型或历史记录。

## 特征与真实参数

119 个局部目标由 25 个点、15 个水平直线、15 个垂直直线、64 个转角组成。形状目标要求中心与对应两个相邻像素亮起，其余存在的正交邻居为空。边界之外视为空。

单层另有 233 个违规目标。对九个 3×3 窗口，先列出全部正例可能出现的局部模式；枚举最小禁止须亮／须空组合，按覆盖最多、约束像素最少、掩码数值最小的顺序贪心覆盖，然后转换为全局像素位置去重。每项只约束 2～5 个像素。它们没有完整或待补角方框模板，提供的是反对证据。

双层的五个目标依次为：每个亮点都有合法局部连接、转角至少四个、转角至多四个、水平直线不少于垂直直线、垂直直线不少于水平直线。标签生成可以使用布尔几何规则，实际前向只使用第一层的连续 sigmoid 响应和训练得到的权重，不运行规则判断器。

特征位置、连接范围与方向由人工指定。所有可训练权重以 NumPy 随机种子 42 独立采样 `U(-0.1,0.1)`，偏置为零；范围以外的连接固定为零。初始化不继承既有模型，也不填入解析形状权重。首次更新前保留原始随机符号；每次 Adam 提案之后按连接方向与参数范围投影。页面分别展示原始梯度、Adam 提案、约束改变量和实际改变量。

单层有 1,977 个可训练参数，双层有 888 个。完整矩阵中还包含结构固定为零的连接，可查看但不属于 Adam 参数。隐藏激活为 sigmoid，输出为 linear。

## 损失与归一化

全部对应损失从第 1 次更新起参与，阶段系数均为 1。损失值和某个参数受到哪些项影响是两回事：损失不依赖该参数时，该项的参数梯度为零。

令批次大小为 N、第一层特征数为 F、输出输入数为 M：

- 分类：`Σ e² / N`；正例 `e=min(s−1.6,0)`，负例 `e=max(s−0.4,0)`。
- 局部监督：`0.2 Σ(h−t)² / (N F)`；目标 t 为须亮／须空条件是否满足的 0 或 1。
- 几何监督：双层使用 `0.2 Σ(g−t)² / (5 N)`；单层界面不显示此项。
- 检测边界：对第一层每个目标的最不利满足输入要求 z≥8，对每个约束像素违约的最不利输入要求 z≤−8，单侧平方误差之和除 F。双层再加入每个真实批次样本的几何输入和 ±4 裕量平方误差，除 `5 N`。
- 输出参与：`Σ min(direction×w−0.02,0)² / M`。支持项方向为正，单层违规项方向为负。

单样本偏导先给出未除归一化分母的数值，再展示系数、分母及对总梯度的贡献。边界项同时包含全局最坏输入约束和双层样本几何约束；单样本视图只能归因后者。输出参与项不以训练样本定义。Adam 使用全部有效项的批次总梯度。

## 训练回放

`geometry-backprop-core.js` 是与旧记录隔离的新数值引擎。清单声明拓扑、激活、稀疏参数顺序、投影边界、损失定义、随机种子、模型哈希和讲解阶段。

每 100 次更新保存一个 gzip JSON 数据块，尾块允许不足 100 次。每块包含起止参数与 Adam 状态，以及每次更新的有序样本、显式标签、损失和真实总梯度。脚本封装支持 `file://`，浏览器按需加载并校验 SHA-256，在 Worker 中重建并复算所选更新；失败时停止显示并允许重试。

两模型正式训练均为 8,000 次，每份六位小数参数穷举 33,554,432 个输入零误判。单层最低正例 1.600235、最高负例 0.555247；双层分别为 1.607734、0.399987。双层五项几何条件亦逐项通过全部输入验证。

JavaScript 独立重算全部 16,000 次更新的损失和梯度，最大梯度误差为 `4.44e-15`，Adam 状态及跨块参数连续性误差为零，两终点舍入后逐项等于正式模型。完整验证结果保存在 `geometry-backprop-verification.json`。

观察画布和历史训练批次严格分开。默认用选中的真实训练样本及更新前参数观察网络；若批次包含居中 3×3，优先选它，否则选择第一个正例。编辑画布不会改写训练记录。最终未舍入状态保留，舍入到六位后逐项对齐正式模型。

## 操作与复现

点击画布格子切换 0／1；触屏、Enter 和空格执行同样操作。右侧并排显示完整输入权重与当前上一层响应乘权重，两侧使用相同色标。第一层为 5×5，深层按真实来源神经元列出全部连接。

特征面板顶部的“黑白灰度”按钮将权重、输入贡献及回放参数图切换到固定灰度：−1 为纯黑，0 为中灰，1 为纯白，中间值线性过渡。超出范围仅截断颜色，显示数值与计算保持完整；未计算值以斜纹和“—”区分。配色可恢复为彩色，刷新、切换模型与导入预设后保留选择。

实时网络结构的“按贡献排序”将直接连接输出的最后隐藏层按 `|响应 × 输出权重|` 降序显示，与输出贡献排行一致；并列时按原神经元编号排序。双隐藏层只排序 H2，H1 保持编号顺序。排序仅改变显示位置，保留真实编号、参数和连接，可一键恢复。画布或历史步骤变化时排序跟随当前观察结果，多输出实验跟随排行中的输出选择，刷新保留开关状态。

```powershell
python llm/scripts/train_geometry_features.py --kind double --steps 8000 --minimum-steps 8000
python llm/scripts/train_geometry_features.py --kind single --steps 12000 --minimum-steps 4000
node llm/tests/geometry-backprop.test.cjs --oracle
node llm/tests/geometry-backprop.test.cjs llm/training-trace/geometry-double-v1/manifest.json llm/geometry-double-model.json --all-gradients
node llm/tests/geometry-backprop.test.cjs llm/training-trace/geometry-single-v1/manifest.json llm/geometry-single-model.json --all-gradients
python llm/scripts/bundle_composition.py
node llm/tests/geometry-teaching.test.cjs
node llm/tests/geometry.browser.cjs
python llm/scripts/build_site.py
```

训练使用 Python、NumPy 2.4.3；浏览器测试使用 Playwright 和 Chromium。正式训练脚本只在全域验收、特征验收和梯度检查全部通过后发布模型文件。失败不会把未通过的候选替换为正式模型。
