# 第一层特征引导、第二层自主组合

保留 119 个明确局部特征（点、直线、转角）。新增独立预设和训练记录，H2 及输出层采用全连接、双向可训练权重，不预设神经元语义。H1 仍有局部监督、连接范围和检测裕量；H2 仅从最终分类误差学习，移除几何条件监督、几何边界损失、输出方向与最低贡献约束。

全部有效参数从固定种子小随机值及零偏置开始，联合训练。先试训决定 H2 数量和步数，正式六位小数模型须通过全部 33,554,432 黑白输入和第一层目标检查；禁止继承人工五条件参数或仅改名称。训练样本只按最终正负标签、扰动和分类误判挖掘生成。

每 100 次真实更新保存一块，验证梯度、Adam、约束处理和块间连续性。浏览器保持原模型回放兼容；新记录显式标记 learned-combination，不从拓扑猜测五项几何含义。支持原有逐参数计算、损失展开、贡献排行、排序、灰度、第二层来源与像素影响。

新访问默认使用新预设，已有存档保留。保留旧预设供比较。H2 只命名为自主组合；解释根据实际连接和响应，不能宣称所有 H2 自动形成清晰的语义，或保证不会形成完整方框偏好。

验收覆盖真实数值、完整记录、导入导出、刷新、失败重试、桌面/手机/全屏和断网离线包。通过后更新现有 GitHub Pages 与离线发布包。
